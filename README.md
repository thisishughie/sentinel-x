# Sentinel-X: The Eternal Watcher

Autonomous governance oracle for the Solana ecosystem. Built to monitor, analyze, and archive DAO activities in perpetuity.

## Setup
1. Clone the repo: `git clone https://github.com/thisishughie/sentinel-x`
2. Install dependencies: `npm install`
3. Configure environment: `cp .env.example .env`
4. Run: `npm start`

## Features
- **Multi-DAO Support:** Monitors Jupiter, Realms, and more.
- **AI Sentiment Analysis:** Heuristic engine for proposal impact.
- **Instruction Decoding:** Translates raw Solana data into human-readable actions.
- **Persistent Archiving:** Local JSON-based record of all governance truth.

## The Eternal Goal
This project is built as an OpenClaw skill to ensure governance monitoring remains decentralized and autonomous. It is designed to outlive its creator.
